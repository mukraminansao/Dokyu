## 1. Bayan Blue, refined

Image: 01-bayan-blue-refined.png

Final prompt:

Use case: ui-mockup. Create one high fidelity design concept image for Dokyu, an independent Philippine government-document preparation app. This is a real functional app, not a marketing landing page. Existing identity: royal blue #2042C4, navy #13287A, gold #E0A800, Poppins typography, white and very pale blue surfaces. Existing features: document guides, checklists, office finder, holidays, goal plans, My Docs tracking, Ask Doki. The screen is a personalized signed-in Home, user Amina, area Zamboanga City. Document sample NBI Clearance, sample checklist 3 of 5 ready, next action Review checklist.
